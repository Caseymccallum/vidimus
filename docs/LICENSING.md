# Licensing

Two licences, on purpose, and this file exists because the reasons matter more than the files do.

**The code is MIT.** Everything under `reference/`, `extension/`, `scripts/` and `spec/`. Use it,
change it, ship it, sell it.

**The specification is CC BY 4.0.** [`RECEIPT-SPEC.md`](RECEIPT-SPEC.md): anyone may implement,
translate or vend it, including inside a product, provided the source is credited.

The split is the one thing in this repository that exists to make adoption easier rather than to
satisfy a licence checklist. A format that cannot be freely reimplemented is not a format; it is a
product with a file extension. The whole point of a receipt is that a stranger can check it, and a
stranger cannot check it with software they are not allowed to write.

The published vector digests, the fixture recipes and the decision record fall under the same
permission as the specification: they are part of it, not part of the code.

`LICENSE` carries the MIT text and nothing else, because a licence file with commentary in it is a
licence file that automated tooling declines to recognise.
